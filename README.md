# Malware Analysis & Digital Forensics

This repository contains the materials and results of my Master's thesis, which explores the relationship between **malware analysis** and **digital forensics**.

The thesis investigates how static and dynamic malware analysis techniques can be combined with digital forensic methods to understand malware behavior, reconstruct malicious activity, and identify digital traces left on compromised systems.

## Scope

The project covers:

* **Static malware analysis** – file hashing, string extraction, executable inspection, and other techniques performed without executing the malware.
* **Dynamic malware analysis** – analyzing malware behavior in a controlled environment using tools such as **FakeNet, Regshot, and Procmon**.
* **Digital forensics** – investigating memory, processes, and file activity using tools such as **Volatility and Velociraptor**.
* **Virtualized analysis environment** – a nested virtual machine setup designed to safely perform malware and forensic analysis.

## Thesis

The complete Master's thesis is available as a PDF in this repository.

The research demonstrates how malware analysis and digital forensics complement each other, providing both an understanding of malicious software and insight into the traces it leaves behind.

## Disclaimer

All malware analysis was performed in an isolated and controlled virtual environment for educational and research purposes.
